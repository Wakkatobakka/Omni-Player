# Omni Player

**Your games, together.**

Omni Player runs supported old mobile games on **Android 11+ / ARM64**, bringing their individual compatibility bridges together in one Android app. The public collection covers BREW, DoJa, J2ME, ExEn and Zeebo/BREW.

**[Download public beta builds](https://github.com/Wakkatobakka/Omni-Player/releases) · [Games, original files and sources](GAME_GUIDE.md) · [Website](https://wakkatobakka.github.io/#games)**

## Download and play

1. Open [Releases](https://github.com/Wakkatobakka/Omni-Player/releases) and download the APK from the newest public beta. Release assets also include its component notices.
2. Install the APK. Android may ask you to allow installs from your browser or file manager.
3. Find your game in the [game guide](GAME_GUIDE.md). Match the listed platform, language and edition when choosing its original files.
4. Open Omni, tap **Load Game**, select the original game file, then launch it from your library.

The bridges are included. You do not need separate bridge downloads.

**Updating?** Install the new public APK over your existing public Omni installation to retain its library and saves.

## Getting the right original files

The [game guide](GAME_GUIDE.md) is the maintained list of supported titles, editions, recognizable filenames, source links and import instructions. You can also [search it on the website](https://wakkatobakka.github.io/#games).

Keep multi-file games in their original ZIP/RAR/7z archive. Supported standalone JAR and EXN files also work. Follow any exception in the game's guide entry; the same title on a different phone platform may be a different game.

ExEn prepares its verified platform support automatically on first use. Connect once, then reuse the offline cache. The original EXEN-V2 Emulator ZIP can also be supplied for offline setup.

Source records distinguish confirmed origins, matching listings and missing information. Recovery, preservation and translation credits remain with the people who did that work.

## Public betas and update history

Current public builds are marked as **prereleases** on GitHub while development and testing continue. Use the [Releases page](https://github.com/Wakkatobakka/Omni-Player/releases) for downloads, included bridge versions, changes and the notices belonging to each build.

A working bridge does not mean every part of a game is bug-free. Bugs and progression blockers can remain; the guide includes known limitations where recorded.

Report problems on the [Issues page](https://github.com/Wakkatobakka/Omni-Player/issues). Include the game and edition, Omni version, Android device, what happened, and a saved report or short recording where possible.

## Files and notices

Original game executables, audio, level data and firmware are not bundled in the public player. Players supply the matching originals. Decorative title/icon artwork is retained.

Each release includes its own component notices. Original games, preserved files, translations and runtime components retain their respective ownership and credits.
